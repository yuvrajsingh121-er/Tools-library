# 📁 Smart File Organizer & Cleanup Utility

A powerful Java Swing desktop application designed to organize cluttered directories automatically and detect duplicate files using SHA-256 cryptographic hashing.

---

## 🚀 Features

- **Categorized Organization:** Moves files into categorized folders (`Images`, `Documents`, `Code_Files`, `Archives`, etc.) based on extensions.
- **SHA-256 Duplicate Finder:** Identifies exact duplicate files by analyzing file content hashes rather than just file names.
- **Interactive Swing GUI:** Easy-to-use interface with a directory browser, logs output, and live progress bars.
- **Multithreaded Performance:** Uses `SwingWorker` threads to ensure the UI remains smooth and responsive during file operations.

---

## 💻 Tech Stack

- **Language:** Java (JDK 11+)
- **GUI Framework:** Java Swing
- **Concurrency:** SwingWorker
- **Hashing Algorithm:** SHA-256
